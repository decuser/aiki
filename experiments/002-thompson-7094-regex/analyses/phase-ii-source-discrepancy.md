# Phase II source-transcription correction

**Status: SUPERSEDED**

During Phase II, the project transcript available at the time represented
location 4 of Thompson's published `a(b|c)*d` object listing as:

```text
4  TRA CODE+13
```

That reading led us to preserve a supposed published/compiler discrepancy.
During Phase IV, the paper was re-transcribed and the page image rechecked. The
published listing actually reads:

```text
4  TRA CODE+16
```

This agrees with Thompson's Stage-3 closure transformation and with the object
word independently produced by the reconstructed compiler. The earlier
`CODE+13` conclusion was therefore a transcription/OCR error, not an error in
Thompson's paper.

The executable corpus has been corrected accordingly: there is now one
authoritative published object program, and word 4 is `TRA CODE+16`.
